# stock-lens · 看懂股票，一页读盘

用 **iFinD（同花顺）** 真实行情与财务数据制作的单页股票速览，覆盖三家代表性 A 股公司：

| 代码 | 名称 | 板块 |
|---|---|---|
| 600519.SH | 贵州茅台 | 白酒 · 消费 |
| 300750.SZ | 宁德时代 | 动力电池 · 新能源 |
| 600036.SH | 招商银行 | 股份制银行 · 金融 |

## 页面内容

- **近一年总览**：最新收盘、近一年涨跌幅、52 周高低、迷你走势图
- **K 线走势**：单股日 K（前复权）+ MA5/MA20 均线 + 成交量，或三只股票归一化涨跌幅对比；支持近 3 月 / 近半年 / 近一年切换，悬停查看明细
- **公司速览**：主营业务、主要产品、控股股东/实控人、竞争对手
- **盈利能力对比**：ROE / ROA / ROIC / 净利率 / 毛利率 / EPS / 每股净资产 / 每股经营现金流（2026 年三季报）
- **名词速查**：ROE、毛利率、EPS、前复权的入门解释

## 运行

纯静态页面，无需构建：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后浏览器打开 `http://localhost:8000`。

## 文件结构

```
index.html   页面（结构 + 样式 + 图表逻辑，Canvas 手绘 K 线）
data.js      iFinD 数据快照（2026-11-18 抓取并内置）
```

## 数据说明

- 行情：iFinD 日 K，2025-11-18 ~ 2026-11-18，A 股前复权，币种 CNY
- 财务：iFinD 财务指标接口，2026 年三季报（截至 2026-09-30），报告期未逐项核验
- 仅供学习参考，不构成投资建议
